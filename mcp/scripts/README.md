# MCP Central scripts

- `../src/mysqlconf_mcp/server.py`: entry point stdio
- `../src/mysqlconf_mcp/config.py`: configuração não secreta do servidor
- `../src/mysqlconf_mcp/contracts/`: schemas de alerta empacotados

O servidor deve ser acionado pelo fluxo local configurado, sem argumentos ou
destinos livres enviados pelo navegador.
