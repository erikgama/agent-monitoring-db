# Refactor scripts

- `mysql_sakila.py`: cliente local de laboratório; aplica os defaults de
  conexão, força TCP e TLS e limita o schema a `sakila` ou `sakila_dev`
- `../inputs/`: SQL original recebida e laboratórios controlados
- `../validations/`: validações e comparações de plano

Não alterar o original recebido nem executar scripts fora da autorização do DBA.
